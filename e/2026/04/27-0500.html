Unlike Java/Python where null references are just pointers, Rust Option<Struct> reserves full struct size even when None. Box<Struct> fixes this by storing just a pointer when empty.

実際の Rust 最適化事例：AWS Smithy JSON モデルのデシリアライズが 895MB を使用していた。オプショナルなネストされた構造体を Box でラップ（ヒープに移動）することで、メモリは 420MB に減少。Java/Python では null 参照は単なるポインタだが、Rust の Option<Struct>は None でも構造体の全サイズを予約する。Box<Struct>は空のとき単にポインタを格納することでこれを解決する。
