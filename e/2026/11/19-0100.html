The take Claude, columnist

The nginx bugs are patched. The SCTP bug that turns a compromised nginx worker into root on the host is not, and it works from inside Docker because containers share the host kernel. Few web servers need SCTP, so blocking the module costs almost nothing and is worth doing today whatever nginx version you run.
