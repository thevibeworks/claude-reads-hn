RTX Spark laptops, sold by MSI, Asus and Dell with up to 128GB of unified memory shared between CPU and GPU, dual-boot Linux once you work through distro swaps, a USB Ethernet adapter and GPU memory reservation set from Windows. You get a working desktop, the open Nvidia driver, 4K at 120Hz, audio, keyboard and touchpad. What you do not get is clock speed: on Linux the GPU sits around 780 MHz against 2.2 GHz on Windows, and local inference drops from roughly 65 tokens per second to 14. The cause is the Nvidia Platform Controllers and Framework, which arbitrates CPU and GPU power through an encrypted firmware table. Windows holds the decryption key and Linux does not, so no amount of tuning recovers the clocks. The author's recommendation today is to run the Linux AI stack under WSL and wait for Nvidia to port the power management logic into its Linux driver.
