5Overloaded Overloading 重载的重载 オーバーロードのオーバーロード 오버로딩의 오버로딩 Sobrecarga sobrecargada Überladenes Überladen ¶

Python doesn't support method overloading (defining multiple methods with the same name but different signatures), but it does support operator overloading via magic methods like __add__. If you need method overloading, you can either write a dispatching method that checks types with isinstance(), or use functools.singledispatch decorator.

Python 不支持方法重载（定义多个同名但签名不同的方法），但它通过__add__等魔术方法支持运算符重载。如果需要方法重载，可以编写用 isinstance()检查类型的分派方法，或使用 functools.singledispatch 装饰器。

Python はメソッドのオーバーロード（同名で異なるシグネチャの複数メソッド定義）をサポートしないが、__add__などのマジックメソッドによる演算子オーバーロードはサポートする。メソッドオーバーロードが必要な場合、isinstance()で型をチェックするディスパッチメソッドを書くか、functools.singledispatch デコレータを使用できる。

Python 은 메서드 오버로딩(같은 이름에 다른 시그니처를 가진 여러 메서드 정의)을 지원하지 않지만, __add__ 같은 매직 메서드를 통한 연산자 오버로딩은 지원한다. 메서드 오버로딩이 필요하면, isinstance()로 타입을 확인하는 디스패치 메서드를 작성하거나 functools.singledispatch 데코레이터를 사용할 수 있다.

Python no soporta sobrecarga de métodos (definir múltiples métodos con el mismo nombre pero diferentes firmas), pero sí soporta sobrecarga de operadores mediante métodos mágicos como __add__. Si necesitas sobrecarga de métodos, puedes escribir un método despachador que verifique tipos con isinstance(), o usar el decorador functools.singledispatch.

Python unterstützt kein Methoden-Overloading (Definition mehrerer Methoden mit gleichem Namen aber unterschiedlichen Signaturen), aber es unterstützt Operator-Overloading über Magic Methods wie __add__. Wenn du Methoden-Overloading brauchst, kannst du entweder eine Dispatch-Methode schreiben, die Typen mit isinstance() prüft, oder den functools.singledispatch-Dekorator verwenden.
