EF Core 11 improves split query performance by batching multiple queries into a single database round-trip instead of sequential calls. When you use AsSplitQuery() to avoid the Cartesian explosion problem with multiple Includes, EF now combines those queries, reducing latency significantly.

EF Core 11 通过将多个查询批量合并为单次数据库往返来提升分割查询性能。当你使用 AsSplitQuery()避免多个 Include 带来的笛卡尔爆炸问题时，EF 现在会合并这些查询，显著减少延迟。

EF Core 11 は、複数のクエリを連続呼び出しではなく単一のデータベースラウンドトリップにバッチ処理することで、分割クエリのパフォーマンスを向上させる。AsSplitQuery()を使用して複数の Include によるデカルト積爆発問題を回避する際、EF はそれらのクエリを結合し、レイテンシを大幅に削減する。

EF Core 11 은 여러 쿼리를 순차적 호출 대신 단일 데이터베이스 왕복으로 배치 처리하여 분할 쿼리 성능을 개선한다. 여러 Include 로 인한 카테시안 폭발 문제를 피하기 위해 AsSplitQuery()를 사용할 때, EF 는 이제 이러한 쿼리들을 결합하여 지연 시간을 크게 줄인다.

EF Core 11 mejora el rendimiento de las consultas divididas agrupando múltiples consultas en un solo viaje de ida y vuelta a la base de datos en lugar de llamadas secuenciales. Cuando usas AsSplitQuery() para evitar el problema de explosión cartesiana con múltiples Includes, EF ahora combina esas consultas, reduciendo significativamente la latencia.

EF Core 11 verbessert die Split-Query-Performance, indem mehrere Abfragen zu einem einzigen Datenbank-Roundtrip gebündelt werden statt sequentieller Aufrufe. Wenn du AsSplitQuery() verwendest, um das kartesische Explosionsproblem mit mehreren Includes zu vermeiden, kombiniert EF diese Abfragen jetzt und reduziert die Latenz erheblich.
