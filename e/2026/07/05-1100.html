34 points39 commentsHN 48792203by enz

Author coins a law: 'A cryptosystem is incoherent if its implementation is distributed by the same entity which it purports to secure against.' Since web apps serve JavaScript from the same server they claim to protect you from, all web-based E2E encryption is theater. The real purpose is legal: companies adopt snake oil crypto to refuse warrant requests by claiming they 'can't' decrypt data, when they technically could push a backdoored update anytime.

作者提出一条定律：'如果密码系统的实现由它声称要保护用户免受的同一实体分发，则该系统是不连贯的。'由于 Web 应用从它们声称要保护你的同一服务器提供 JavaScript，所有基于 Web 的端到端加密都是戏剧。真正的目的是法律上的：公司采用骗人的加密来拒绝搜查令请求，声称他们'不能'解密数据，而实际上他们随时可以推送后门更新。

著者は法則を提唱：「暗号システムの実装が、それが保護すると主張する対象と同じ主体によって配布される場合、そのシステムは非論理的である。」Web アプリはあなたをガードするはずのサーバーから JavaScript を提供するため、ウェブベースの E2E 暗号化はすべて芝居。本当の目的は法的なもの：企業はインチキ暗号を採用して令状要求を拒否し、データを「解読できない」と主張するが、技術的にはいつでもバックドア付きアップデートをプッシュできる。

저자는 법칙을 제안한다: '암호 시스템의 구현이 그것이 보호한다고 주장하는 동일한 주체에 의해 배포된다면, 그 시스템은 비논리적이다.' 웹 앱이 당신을 보호한다고 주장하는 동일한 서버에서 JavaScript 를 제공하기 때문에, 모든 웹 기반 E2E 암호화는 연극이다. 진짜 목적은 법적인 것: 회사들은 기술적으로 언제든지 백도어 업데이트를 푸시할 수 있으면서도 데이터를 '해독할 수 없다'고 주장하며 영장 요청을 거부하기 위해 사기성 암호화를 채택한다.

El autor acuña una ley: 'Un criptosistema es incoherente si su implementación es distribuida por la misma entidad contra la que pretende proteger.' Como las apps web sirven JavaScript desde el mismo servidor del que dicen protegerte, toda la encriptación E2E web es teatro. El verdadero propósito es legal: las empresas adoptan cripto fraudulenta para rechazar órdenes judiciales alegando que 'no pueden' descifrar datos, cuando técnicamente podrían enviar una actualización con puerta trasera en cualquier momento.

Der Autor prägt ein Gesetz: 'Ein Kryptosystem ist inkohärent, wenn seine Implementierung von derselben Entität verteilt wird, vor der es zu schützen vorgibt.' Da Web-Apps JavaScript vom gleichen Server liefern, vor dem sie dich angeblich schützen, ist alle webbasierte E2E-Verschlüsselung Theater. Der wahre Zweck ist rechtlich: Unternehmen übernehmen Schwindel-Krypto, um Durchsuchungsbefehle abzulehnen und zu behaupten, sie 'können' Daten nicht entschlüsseln, obwohl sie technisch jederzeit ein Update mit Hintertür pushen könnten.
