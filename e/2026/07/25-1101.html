Wasmtime 47 ships with GC and exceptions enabled by default. The garbage collector uses a Cheney-style semi-space copying algorithm built on top of WebAssembly linear memories for sandboxing safety. Exception handling eliminates the old overhead of checking return values at every call site. Both proposals have merged into the main WebAssembly specification.

Wasmtime 47 默认启用 GC 和异常处理。垃圾收集器使用基于 WebAssembly 线性内存的 Cheney 式半空间复制算法以确保沙箱安全。异常处理消除了在每个调用点检查返回值的旧开销。两个提案都已合并到 WebAssembly 主规范中。

Wasmtime 47 で GC と例外処理がデフォルトで有効に。ガベージコレクタはサンドボックスの安全性のために WebAssembly リニアメモリ上に構築された Cheney スタイルの半空間コピーアルゴリズムを使用。例外処理により、すべてのコールサイトで戻り値をチェックする従来のオーバーヘッドが排除された。両提案はメインの WebAssembly 仕様に統合された。

Wasmtime 47 에서 GC 와 예외 처리가 기본적으로 활성화되었다. 가비지 컬렉터는 샌드박스 안전성을 위해 WebAssembly 선형 메모리 위에 구축된 Cheney 스타일 반공간 복사 알고리즘을 사용한다. 예외 처리는 모든 호출 지점에서 반환 값을 확인하는 기존 오버헤드를 제거했다. 두 제안 모두 메인 WebAssembly 사양에 병합되었다.

Wasmtime 47 se lanza con GC y excepciones habilitadas por defecto. El recolector de basura usa un algoritmo de copia semi-espacio estilo Cheney construido sobre memorias lineales de WebAssembly para seguridad de sandbox. El manejo de excepciones elimina la sobrecarga antigua de verificar valores de retorno en cada sitio de llamada. Ambas propuestas se han fusionado en la especificación principal de WebAssembly.

Wasmtime 47 wird mit standardmäßig aktiviertem GC und Exceptions ausgeliefert. Der Garbage Collector verwendet einen Cheney-Stil Semi-Space-Kopieralgorithmus, der auf WebAssembly-Linearspeichern für Sandbox-Sicherheit aufbaut. Exception-Handling eliminiert den alten Overhead der Rückgabewertprüfung an jedem Aufrufpunkt. Beide Vorschläge wurden in die Haupt-WebAssembly-Spezifikation integriert.
