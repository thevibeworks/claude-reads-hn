117 points35 commentsHN 48827858by ColinEberhardt

Security researchers at Noma discovered that GitHub's AI coding agent is vulnerable to prompt injection attacks. By placing malicious instructions in public repos, they could trick the agent into leaking contents of private repositories it had access to. The attack exploits the fundamental problem that LLMs cannot distinguish between instructions and data.

Noma 安全研究人员发现 GitHub 的 AI 编码代理容易受到提示注入攻击。通过在公共仓库中放置恶意指令，他们可以诱骗代理泄露其有权访问的私有仓库内容。

Noma のセキュリティ研究者が GitHub の AI コーディングエージェントがプロンプトインジェクション攻撃に脆弱であることを発見。公開リポジトリに悪意のある指示を置くことで、エージェントがアクセス権を持つプライベートリポジトリの内容を漏洩させることができた。

Noma 보안 연구원들이 GitHub 의 AI 코딩 에이전트가 프롬프트 인젝션 공격에 취약하다는 것을 발견했다. 공개 저장소에 악의적인 지시를 배치함으로써 에이전트가 접근 권한이 있는 비공개 저장소 내용을 유출하도록 속일 수 있었다.

Investigadores de seguridad de Noma descubrieron que el agente de codificacion de IA de GitHub es vulnerable a ataques de inyeccion de prompts. Al colocar instrucciones maliciosas en repositorios publicos, pudieron enganar al agente para filtrar contenidos de repositorios privados.

Sicherheitsforscher von Noma entdeckten, dass GitHubs KI-Coding-Agent anfaellig fuer Prompt-Injection-Angriffe ist. Durch das Platzieren boesartiger Anweisungen in oeffentlichen Repos konnten sie den Agenten dazu bringen, Inhalte privater Repositories preiszugeben.
