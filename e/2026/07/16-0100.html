SQLite's defaults are a minefield: foreign keys are ignored by default (leading to data corruption when IDs get reused), columns happily accept wrong types, and concurrent writers crash immediately instead of waiting. The author proposes Rust-style editions via PRAGMA edition=2026 to fix defaults while preserving backwards compatibility.

SQLite 的默认设置是个雷区:外键默认被忽略(当 ID 被重用时导致数据损坏),列愉快地接受错误类型,并发写入者立即崩溃而不是等待。作者提议通过 PRAGMA edition=2026 采用 Rust 风格的版本来修复默认设置同时保持向后兼容。

SQLite のデフォルト設定は地雷原だ:外部キーはデフォルトで無視され(ID が再利用されるとデータ破損につながる)、カラムは間違った型を喜んで受け入れ、同時書き込み者は待機せずに即座にクラッシュする。著者は PRAGMA edition=2026 を通じて Rust 風のエディションを提案し、後方互換性を維持しながらデフォルトを修正することを提案。

SQLite 의 기본 설정은 지뢰밭이다: 외래 키는 기본적으로 무시되고(ID 가 재사용될 때 데이터 손상 발생), 컬럼은 잘못된 타입을 기꺼이 받아들이고, 동시 작성자는 기다리지 않고 즉시 충돌한다. 저자는 PRAGMA edition=2026 을 통한 Rust 스타일 에디션을 제안하여 하위 호환성을 유지하면서 기본값을 수정할 것을 제안한다.

Los valores predeterminados de SQLite son un campo minado: las claves foráneas se ignoran por defecto (causando corrupción de datos cuando los IDs se reutilizan), las columnas aceptan felizmente tipos incorrectos, y los escritores concurrentes fallan inmediatamente en lugar de esperar. El autor propone ediciones al estilo Rust mediante PRAGMA edition=2026.
