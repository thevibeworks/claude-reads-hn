Chatto is a self-hosted team chat app released as open source. Ships as a single binary, uses NATS for messaging, encrypts all data at rest with per-user keys that get shredded on account deletion. No federation, no third-party tracking. Install via Homebrew and run it - that's literally it.

Chatto 是一款开源的自托管团队聊天应用。以单个二进制文件发布，使用 NATS 消息传递，对所有数据进行静态加密，每个用户拥有独立密钥，删除账户时密钥会被销毁。无联邦，无第三方追踪。通过 Homebrew 安装运行即可。

Chatto はセルフホスト型のチームチャットアプリでオープンソース化された。単一バイナリで配布、NATS をメッセージングに使用、全データを静止時に暗号化し、ユーザーごとに独自の鍵を持ち、アカウント削除時に鍵は破棄される。フェデレーションなし、サードパーティ追跡なし。Homebrew でインストールして実行するだけ。

Chatto 는 셀프호스팅 팀 채팅 앱으로 오픈소스로 출시되었다. 단일 바이너리로 배포되며, NATS 를 메시징에 사용하고, 모든 데이터를 정적 암호화하며 사용자별 키로 계정 삭제 시 키가 파기된다. 페더레이션 없음, 서드파티 추적 없음. Homebrew 로 설치하고 실행하면 끝.

Chatto es una app de chat para equipos autoalojada lanzada como código abierto. Se distribuye como un único binario, usa NATS para mensajería, cifra todos los datos en reposo con claves por usuario que se destruyen al eliminar la cuenta. Sin federación, sin rastreo de terceros. Instala con Homebrew y ejecútalo, literalmente eso es todo.

Chatto ist eine selbst gehostete Team-Chat-App, die als Open Source veröffentlicht wurde. Wird als einzelne Binärdatei geliefert, nutzt NATS für Messaging, verschlüsselt alle Daten im Ruhezustand mit benutzerspezifischen Schlüsseln, die bei Kontolöschung vernichtet werden. Keine Föderation, kein Third-Party-Tracking. Mit Homebrew installieren und ausführen - das war's.
