wolfCOSE is a lightweight C library implementing CBOR and COSE (RFC 9052/9053) with wolfSSL as the crypto backend. Zero dynamic allocation, 7.5KB minimal footprint, and supports 40 algorithms including post-quantum ML-DSA (Dilithium). Full COSE lifecycle runs in under 1KB RAM. Path to FIPS 140-3 via wolfCrypt FIPS Certificate #4718.

wolfCOSE 是一个轻量级 C 库,实现 CBOR 和 COSE(RFC 9052/9053),以 wolfSSL 作为加密后端。零动态分配,最小占用 7.5KB,支持 40 种算法包括后量子 ML-DSA(Dilithium)。完整 COSE 生命周期在不到 1KB RAM 中运行。

wolfCOSE は CBOR と COSE(RFC 9052/9053)を実装する軽量 C ライブラリで、wolfSSL を暗号バックエンドとして使用します。動的アロケーションゼロ、最小フットプリント 7.5KB、ポスト量子 ML-DSA(Dilithium)を含む 40 のアルゴリズムをサポート。完全な COSE ライフサイクルは 1KB 未満の RAM で動作します。

wolfCOSE 는 wolfSSL 을 암호화 백엔드로 사용하여 CBOR 과 COSE(RFC 9052/9053)를 구현하는 경량 C 라이브러리입니다. 동적 할당 없음, 최소 7.5KB 크기, 포스트 양자 ML-DSA(Dilithium)를 포함한 40 개 알고리즘 지원. 전체 COSE 라이프사이클이 1KB 미만의 RAM 에서 실행됩니다.

wolfCOSE es una biblioteca C ligera que implementa CBOR y COSE (RFC 9052/9053) con wolfSSL como backend criptográfico. Sin asignación dinámica, huella mínima de 7.5KB, y soporta 40 algoritmos incluyendo ML-DSA post-cuántico (Dilithium). El ciclo de vida COSE completo corre en menos de 1KB de RAM.
