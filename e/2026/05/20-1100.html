CVE-2026-31431 (CopyFail) is a kernel memory corruption flaw that gives attackers a controlled 4-byte write into the Linux page cache. It works by confusing IPSec ESP code via AF_ALG sockets. Unlike typical kernel exploits, it's deterministic and portable across kernels from 2017-2026. Attack paths include cross-container poisoning (corrupt shared image layers in page cache to backdoor neighboring pods) and full container escape (poison runc binary to get host root on next kubectl exec).
