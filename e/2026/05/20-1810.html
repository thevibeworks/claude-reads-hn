3Saying Goodbye to Asm.js 告别 Asm.js Asm.js への別れ Asm.js 에게 작별을 Diciendo adios a Asm.js Abschied von Asm.js ¶

201 points93 commentsHN 48206340by eqrion

Mozilla is disabling asm.js optimizations in Firefox 148 and plans to remove the code entirely. OdinMonkey, their asm.js compiler shipped in Firefox 22 (2013), enabled Unity and Unreal to run in browsers and directly led to WebAssembly. The code still runs as regular JS, but Mozilla recommends recompiling to WebAssembly for better performance.
