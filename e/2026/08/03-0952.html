Rust is introducing Move and Forget traits to let types opt out of being relocated in memory or forgotten via mem::forget. This would finally make self-referential types a property of the type itself rather than the weird Pin abstraction. The goal: safe scoped spawn for async, proper async drop, and simplified kernel code for Rust-for-Linux.

Rust 正在引入 Move 和 Forget trait，让类型可以选择不被重新定位到内存中或通过 mem::forget 被遗忘。这将最终使自引用类型成为类型本身的属性，而不是奇怪的 Pin 抽象。目标是：为 async 实现安全的作用域 spawn、正确的 async drop，以及简化 Rust-for-Linux 的内核代码。

Rust は Move と Forget トレイトを導入し、型がメモリ内での再配置や mem::forget による忘却をオプトアウトできるようにします。これにより、自己参照型が奇妙な Pin 抽象化ではなく、型自体のプロパティになります。目標は、async の安全なスコープ付き spawn、適切な async drop、Rust-for-Linux のカーネルコードの簡素化です。

Rust 는 Move 와 Forget 트레이트를 도입하여 타입이 메모리에서 재배치되거나 mem::forget 으로 잊혀지는 것을 거부할 수 있게 합니다. 이로써 자기 참조 타입이 이상한 Pin 추상화가 아닌 타입 자체의 속성이 됩니다. 목표는 async 를 위한 안전한 스코프 spawn, 적절한 async drop, Rust-for-Linux 커널 코드 단순화입니다.

Rust está introduciendo los traits Move y Forget para permitir que los tipos opten por no ser reubicados en memoria o ser olvidados via mem::forget. Esto finalmente haría que los tipos auto-referenciales sean una propiedad del tipo mismo en lugar de la extraña abstracción Pin.
