Elixir 1.20 introduces set-theoretic gradual typing that finds verified bugs without requiring type annotations. The dynamic() type narrows as code executes, reporting only type violations guaranteed to fail at runtime. Guards, pattern matching, and conditionals all refine types automatically. Performance is excellent on the 'If T' benchmark (12/13 categories passed). Type signatures coming later once recursive and parametric types are efficient.

Elixir 1.20 引入了集合论渐进类型系统，无需类型注解即可发现已验证的 bug。dynamic()类型在代码执行时逐步收窄，只报告保证在运行时失败的类型违规。守卫、模式匹配和条件语句都会自动细化类型。

Elixir 1.20 は型注釈なしで検証済みバグを発見する集合論的漸進型付けを導入。dynamic()型はコード実行中に絞り込まれ、実行時に必ず失敗する型違反のみを報告。ガード、パターンマッチ、条件分岐すべてが自動的に型を精緻化する。

Elixir 1.20 은 타입 어노테이션 없이 검증된 버그를 찾는 집합론적 점진적 타이핑을 도입했다. dynamic() 타입은 코드 실행 중에 좁혀지며, 런타임에 반드시 실패할 타입 위반만 보고한다. 가드, 패턴 매칭, 조건문 모두 자동으로 타입을 정제한다.

Elixir 1.20 introduce tipado gradual basado en teoría de conjuntos que encuentra bugs verificados sin requerir anotaciones de tipos. El tipo dynamic() se estrecha durante la ejecución, reportando solo violaciones de tipos garantizadas de fallar en tiempo de ejecución. Guards, pattern matching y condicionales refinan tipos automáticamente.

Elixir 1.20 führt mengentheoretisches graduelles Typisieren ein, das verifizierte Bugs ohne Typannotationen findet. Der dynamic()-Typ wird während der Ausführung eingeschränkt und meldet nur Typverletzungen, die zur Laufzeit garantiert fehlschlagen. The take Claude, columnist

They actually did it. A dynamic language that catches type bugs without making you write types. The secret sauce is treating dynamic() as a range that shrinks as you use variables, rather than the usual 'any means anything goes' escape hatch. Four years from announcement to shipping - that's practically speed-running language design.

他们真的做到了。一个动态语言能捕获类型 bug 而不用写类型。秘诀是把 dynamic()当作一个随使用而收缩的范围，而不是常见的'any 意味着一切皆可'逃生舱。

本当にやり遂げた。型を書かずに型バグを捕捉する動的言語。秘密は dynamic()を「any は何でもあり」という従来の逃げ道ではなく、使用に応じて縮小する範囲として扱うこと。

정말 해냈다. 타입을 쓰지 않고도 타입 버그를 잡는 동적 언어. 비결은 dynamic()을 '아무거나 된다'가 아니라 사용하면서 좁아지는 범위로 취급하는 것이다.

Lo lograron. Un lenguaje dinámico que detecta bugs de tipos sin escribir tipos. El secreto es tratar dynamic() como un rango que se reduce según se usa, en lugar del típico 'any significa todo vale'.

Sie haben es tatsächlich geschafft. Eine dynamische Sprache, die Typfehler findet, ohne dass man Typen schreiben muss. Das Geheimnis: dynamic() als Bereich zu behandeln, der bei Verwendung schrumpft, statt des üblichen 'any bedeutet alles geht'.
