75 points63 commentsHN 48405019by xena

IPv6 link-local addresses need a 'zone' suffix to specify which interface to use (like fe80::4%eth0). When you put this in a URL, the percent sign needs to be percent-encoded to %25, giving you monstrosities like http://［fe80::4%25eth0］:80. This is RFC 6874 compliant but breaks everyone's brain and half the URL parsers in existence.

IPv6 链路本地地址需要'区域'后缀来指定接口。当你把它放在 URL 中，百分号需要被编码为%25，产生类似 http://［fe80::4%25eth0］:80 的怪物。符合 RFC 6874 但让人崩溃。

IPv6 リンクローカルアドレスにはインターフェースを指定する「ゾーン」サフィックスが必要。URL に入れるとパーセント記号を%25 にエンコードする必要があり、http://［fe80::4%25eth0］:80 のような怪物が生まれる。

IPv6 링크 로컬 주소는 인터페이스를 지정하는 '존' 접미사가 필요하다. URL 에 넣으면 퍼센트 기호를 %25 로 인코딩해야 하고, http://［fe80::4%25eth0］:80 같은 괴물이 탄생한다.

Las direcciones IPv6 link-local necesitan un sufijo de 'zona' para especificar la interfaz. En una URL, el signo de porcentaje debe codificarse como %25, creando monstruosidades como http://［fe80::4%25eth0］:80.

IPv6 Link-Local-Adressen brauchen ein 'Zone'-Suffix zur Interface-Angabe. In einer URL muss das Prozentzeichen als %25 kodiert werden, was Ungetüme wie http://［fe80::4%25eth0］:80 erzeugt.

WSL2 recibió una corrección que da a cada dispositivo virtio su propio pool DMA dedicado. Los montajes virtiofs y el adaptador de red ya no pelean por el mismo buffer.
