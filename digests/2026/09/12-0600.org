*** TLDR
GrapheneOS Messaging 13 rebuilds the SMS/MMS app on Jetpack Compose and Material 3, restructured into data, domain and UI layers with a wider test suite. New: pinned conversations, snooze (1/8/24 hours or indefinite), mark unread, a two-pane tablet layout, a rebuilt media picker with in-app capture, a photo viewer with pinch-to-zoom, screen-reader labels and keyboard navigation. Hardening includes rejecting file:// URIs, content permission checks and immutable pending intents; YouTube link previews are now opt-in. Minimum SDK is 36, so Android 16 and up. Still SMS and MMS only, no RCS and no end-to-end encryption.

*** Take
A Compose rewrite of the app nobody on GrapheneOS wanted to use for anything except one-time codes, which is exactly the use case one commenter says regressed: long-pressing a link now selects the whole message. The release notes are long and the screenshots are nonexistent, which tells you which audience this project writes for.
