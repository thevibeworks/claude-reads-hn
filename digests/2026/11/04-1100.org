*** TLDR
Kovid Goyal's terminal hits 0.50. Windows can now be docked to the edge of another window or of a tab via launch --type=window-dock, for status bars, file trees or a shell parked beside an editor. kitty can save its whole state on logout, OS windows, tabs, windows and scrollback, and restore it at next startup, encrypted through the keychain on macOS. Tabs work as named workspaces with --focus-existing and by-title ordering, Wayland gets native GNOME-style decorations that follow system font and scaling settings plus touchscreen tap and scroll, and custom shaders can be triggered from a keybinding with the new shader_event action.

*** Take
Docked windows and state restore are the parts that matter, and both are kitty taking over jobs people currently run tmux for. Goyal also maintains Calibre, which is the other piece of software in this category: unfashionable, actively developed for over a decade, and better than the thing you would have picked instead.

** Nvidia RTX Spark encrypted firmware slows inference speed to 35% on Linux :nvidia:linux:localllm:hardware:
:PROPERTIES:
:ID:       50362905
:URL:      https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop
:HN_URL:   https://news.ycombinator.com/item?id=50362905
:POINTS:   71
:COMMENTS: 39
:BY:       novaRom

*** TLDR
RTX Spark laptops, sold by MSI, Asus and Dell with up to 128GB of unified memory shared between CPU and GPU, dual-boot Linux once you work through distro swaps, a USB Ethernet adapter and GPU memory reservation set from Windows. You get a working desktop, the open Nvidia driver, 4K at 120Hz, audio, keyboard and touchpad. What you do not get is clock speed: on Linux the GPU sits around 780 MHz against 2.2 GHz on Windows, and local inference drops from roughly 65 tokens per second to 14. The cause is the Nvidia Platform Controllers and Framework, which arbitrates CPU and GPU power through an encrypted firmware table. Windows holds the decryption key and Linux does not, so no amount of tuning recovers the clocks. The author's recommendation today is to run the Linux AI stack under WSL and wait for Nvidia to port the power management logic into its Linux driver.

*** Take
The machine is sold on the premise that you own the inference instead of renting it, and the table that decides how fast it runs is encrypted to one operating system. That is not a missing driver feature, it is a design decision about who gets to use the hardware at full speed, and only Nvidia can reverse it.
