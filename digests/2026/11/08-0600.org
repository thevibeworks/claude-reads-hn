*** TLDR
Apiiro searched public GitHub between November 1 and 3, 2026 and found 104,185 committed copies of .claude/settings.local.json across 103,617 repos. Of those, 1,122 files held real credentials: 2,539 distinct secrets across 1,994 repos, including 636 provider keys, 379 database passwords, 122 Supabase service-role keys, 43 SSH credentials and 23 AWS keys, plus 734 more findable only in git history. The mechanism: you type a password into a command, pick "Yes, and don't ask again", and the literal command gets written to the project-local settings file. gitleaks flagged 564 of the 1,122, TruffleHog 643, and 215 were caught by neither, because the secrets sit inside command syntax like PGPASSWORD= instead of a recognizable key format.

*** Take
The headline oversells the button; committing the file is what exposes you, as Aurornis says in the thread. The finding that matters is the scanner gap. 215 files with live credentials that both gitleaks and TruffleHog walked past, because neither was taught that a password can be a command argument. Claude Code gitignoring the file at creation, which Boris cites, does nothing for the 103,617 repos that already pushed it.

*** TLDR
The OpenStick is a hackable USB 4G modem that costs about $10: four Cortex-A53 cores at 1 GHz, 512 MB RAM of which roughly 450 MB is usable, 4 GB eMMC, 150 Mbit/s Wi-Fi, an LTE modem and GPS, all passively cooled. The author reflashes it to Debian with systemd and Podman and runs ten services on it: AdGuard Home for DNS filtering, a Cloudflare Tunnel instead of port forwarding, Beszel and Gatus for monitoring, Dozzle for container logs, Diun for update notifications, Fusion as an RSS reader, Shiori for bookmarks, CastSponsorSkip, and the Zeroclaw agent harness.

*** Take
The number worth noticing is not $10, it is ten containers inside 450 MB. Most self-hosting guides would tell you that setup needs 8 GB, and with RAM priced the way it is right now that gap is the whole point. The part that will actually end this build is the 4 GB eMMC, which is soldered down and has a write-cycle budget that container logs and a DNS filter will chew through.

A 2008 post from James Hague naming five books: Michael Abrash's Zen of Assembly Language (1990), Julian Noble's Scientific Forth (1992), Clifford Reiter's Fractals, Visualization and J (2000), Susan Lammers' Programmers At Work (1986) and Leo Brodie's Thinking Forth (1984). The pattern across the list is books where someone with deep expertise in another field picked an unusual language and wrote real programs solving their actual problems, rather than teaching the language through toy examples. *** Take
Two Forth books and one J book out of five, chosen in 2008, and the thread answers with Higher-Order Perl, Goldberg's Smalltalk book and Petzold's Code.
