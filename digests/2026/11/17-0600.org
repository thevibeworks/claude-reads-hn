*** TLDR
On 16 November an attacker wrote malicious code into the 'Project JavaScript' field of Optimizely Web customer projects, so Optimizely's own CDN served it to visitors of 178 organisations including Zoom, the BBC, CNN, GitLab, IKEA, HSBC and Equifax. Report URI says the payload, rebuilt 26 times that day, swapped crypto wallet addresses (about $7,040 stolen), skimmed card numbers typed into site forms, sent cookies and screenshots out, and loaded the Coruna and DarkSword exploit chains on older iOS. Only 24 of the affected hosts had a CSP strict enough to block it. How the attacker got write access across unrelated customers is unknown, and Optimizely had not responded at publication.

*** Take
Every one of these sites gave a marketing A/B testing tool the right to run arbitrary code on its checkout pages, and the tool's write access was apparently shared across customers. CSP worked for the few sites that kept it strict. The rest are now telling customers to watch their card statements. The report is written by a vendor selling detection products, so read its tool claims accordingly.

*** TLDR
A beginner's introduction to chemical reaction network theory, following Martin Feinberg. Reactions are written as vectors in species space, their span is the stoichiometric subspace, and concentrations can only move within one shifted copy of it. Under mass-action kinetics, equilibria are where rate-weighted reaction vectors sum to zero. The deficiency, number of complexes minus linkage classes minus subspace dimension, then constrains behaviour without knowing rate constants. If it is zero and the network is weakly reversible, each class has exactly one stable equilibrium and no oscillations. Michaelis-Menten has deficiency zero but is not weakly reversible, so it has no strictly positive equilibrium.

*** Take
The content is good: the deficiency zero theorem tells you whether a network can oscillate or have multiple steady states using only its structure and linear algebra, which is useful when rate constants are unknown. The title is the problem. It covers reaction kinetics only, and commenters who expected molecular shape and electron distribution felt misled. 'Reaction kinetics is linear algebra' would have been accurate.
