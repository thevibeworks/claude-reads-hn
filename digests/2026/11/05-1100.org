*** TLDR
OpenAI shipped Images 2.6 across ChatGPT, Codex and the API in two variants, GPT-Image-2.6 Flare and GPT-Image-2.6 Sunburst. The claims: generation 50% faster than before, as little as six seconds per image on Flare at low quality, animated GIF output, image markup, SVG export in the API, and a complexity parameter that controls how much the model plans before it draws. Available globally today on every ChatGPT tier. OpenAI says more than 4 billion images a week are now created across its products.

*** Take
SVG export is the only line here that changes a workflow, because a vector file is something a designer can open and edit and a PNG is something they have to redo. Everything else is latency. The sharpest reply in the thread is preommr arguing image quality peaked around early Midjourney and has drifted since, and the 4-billion-a-week figure quietly agrees: this is a volume business now, not a quality race.

*** TLDR
Zig's October devlog removes defined precedence for some operator combinations and makes the compiler require parentheses where precedence no longer exists. Within a group you still write code as before: the multiplicative set ⁎ / ⁎% ⁎| %, the additive set + - +% -% +| -|, the comparisons, and and/or. Most languages answer precedence confusion with a table in the docs and a lint rule nobody enables. Zig moved it into the compiler, which is the only place a rule like this gets enforced. The cost is more parentheses; the return is never having to remember whether % binds tighter than ⁎. The 353 lines they had to fix in their own tree is the useful detail: they were writing these expressions too.
