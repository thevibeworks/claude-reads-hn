*** TLDR
USPS is selling ZIP Code boundary polygons built from its own delivery address and location data, updated quarterly, in three license tiers: Internal, Enterprise and Publication. Access requires a signed license agreement and order form, and the license bars redistribution without written consent. The page lists no prices; commenters who opened the order form report the cheapest tier at $10,000 a year.

*** Take
USPS is the one party that actually knows where its delivery routes run, so this is the only dataset with a real claim to being authoritative, and it costs $10,000 to look at. The sharper objection in the thread is technical: a ZIP code is a set of delivery points, not an area, so a polygon file is a confident answer to a question that has no clean answer. Free Census ZCTA shapefiles are wrong in roughly the same way, for $0.

*** TLDR
Meta FAIR published E-means, a replacement for Lloyd's algorithm in k-means. Instead of recomputing cluster means over the full batch each epoch, it keeps exponential moving averages of per-cluster sums and counts, so old assignments decay at rate alpha.
