*** TLDR
Robert Haas explains that PostgreSQL 19 slipped from its usual September-October window to November because LLM-assisted bug hunting is surfacing defects faster than the project can absorb them. Commits to master went from 1,037 in 2025 to 1,443 in 2026, a 60% rise, and commits to older release branches rose 74%. Several features were reverted late in the beta cycle. Machine-found bugs still need human review to meet project standards, and security work on back branches pushed release candidate review back.

*** Take
Finding bugs got cheap and fixing them did not, so the bottleneck moved to the committers. A 40-year-old codebase giving up this many latent defects is good news that happens to look like a missed deadline.

A site launched in October 2026 by laid-off engineers who want to rebuild expensive SaaS platforms as Apache-2.0 self-hostable software, with Occupy Wall Street framing against per-seat pricing and vendor lock-in. The method is clean-room: turn public API docs into written specs, keep spec writers separate from implementers, have AI write the code under human review, then test compatibility against the vendor's own SDKs. *** Take
The clean-room discipline is the only serious part of this, and it is the part a tired contributor will skip first. Rebuilding Auth0's API surface is a weekend demo; staying compatible through five years of the vendor's changes is the actual job nobody in the thread volunteered for.

*** TLDR
Marc Kerbiquet's BSD-licensed C replacement, last updated June 2026. It has type inheritance, generics, multiple return values, optional types for null safety, deferred statements, iterators, no header files, order-independent definitions, and a self-hosted compiler built for fast compilation. The stated design goal is minimalism, written so one person with limited time can hold the whole language in their head. Syntax borrows from Ruby.

*** Take
A one-person C replacement is a legitimate thing to build and the honest framing here beats the usual safety pitch. The HN thread lands on the real problem: a language built to fit one person's head has syntax that only fits that head, and the declaration-versus-literal inconsistency is what everyone noticed first.
