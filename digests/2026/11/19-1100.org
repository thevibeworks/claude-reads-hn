*** TLDR
A hardware and software hacker lists six months of agent-assisted reverse engineering. The projects include custom firmware for the Arturia MiniFreak, Teenage Engineering OP-Z, Akai MPC Sample and Xteink X4 e-reader; protocol maps for two Sony Alpha cameras (one became a wireless webcam) and an emWave biofeedback device; a fixed macOS driver for an HP P2055dn printer; and a decoded proprietary image format. The main model is DeepSeek v4.1 Flash, chosen for speed and cost, with Codex used sometimes. Ghidra over an MCP bridge is the main tool, with radare2 for quick CLI work. Probes are written in Python and the final hacks in Rust, because the strict compiler gives the agent precise errors. The workflow: identify the binary, have the agent keep every finding in Markdown files so the work survives context compaction, map the structure, then use breakpoints, injected logging or emulators when static reading stalls. The most specific tip is a hypothesis skill: the agent writes each hypothesis, experiment and result to a CSV, so it has to run a test instead of guessing in circles.

*** Take
The hypothesis CSV is the one idea here you can reuse tomorrow. It turns the agent's habit of retrying random fixes into a log you can read and correct. The post spends little time on what failed, so treat the project list as a highlight reel. The thread shows another constraint: komali2 says Anthropic and OpenAI models refuse reverse-engineering work, which is why people, including this author, end up on DeepSeek.
