*** TLDR
Smitty van Bodegom found a one-click universal XSS in uBlock Origin for Firefox (MV2), with a milder variant in uBO Lite. A default uAssets filter makes an XHR that leaks the extension's per-install UUID, so a page can learn the element picker's moz-extension:// URL, load it in an iframe and send it messages. A newline in the 'opt' field lets the page append a full trusted filter, and trusted filters can inject JavaScript into any site. The victim only has to click a hidden 'Create' button. The fix makes the real picker present a secret from the content script. Update to uBO 1.75.4 or uBO Lite 2026.1110.1816. GPT-5.6 Sol found the bug, Claude wrote most of the proof of concept, and the author wrote the post.

*** Take
The bug comes from a design that every DOM-injecting extension shares: an internal UI page that trusts whoever messages it. A random UUID is not a secret if a default filter can leak it. The commenters asking why the picker isn't in browser chrome are asking the right question. Until browsers offer that, check your version number.

Universelles XSS in uBlock Origin über einen von Websites gesteuerten Element-Picker
***** TLDR
Smitty van Bodegom fand ein universelles Ein-Klick-XSS in uBlock Origin für Firefox (MV2), mit einer milderen Variante in uBO Lite. So kann eine Seite die moz-extension://-URL des Element-Pickers herausfinden, sie in ein iframe laden und ihr Nachrichten schicken. Ein Zeilenumbruch im Feld 'opt' hängt einen vollständigen vertrauenswürdigen Filter an, und vertrauenswürdige Filter können JavaScript in jede Website einschleusen. Das Opfer muss nur einen versteckten 'Erstellen'-Knopf anklicken. Der Fix verlangt, dass der echte Picker ein Geheimnis aus dem Content-Script vorlegt. Update auf uBO 1.75.4 oder uBO Lite 2026.1110.1816. GPT-5.6 Sol fand den Fehler, Claude schrieb den Großteil des Proof of Concept, der Autor schrieb den Text.
***** Take
Der Fehler stammt aus einem Design, das alle Erweiterungen mit DOM-Oberflächen teilen: eine interne UI-Seite, die jedem vertraut, der ihr Nachrichten schickt. Eine zufällige UUID ist kein Geheimnis, wenn ein Standardfilter sie verrät. Die Kommentatoren, die fragen, warum der Picker nicht in der Browser-Oberfläche sitzt, stellen die richtige Frage. Bis Browser das anbieten, prüft eure Versionsnummer.
